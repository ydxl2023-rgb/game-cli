# Mail 验收

独立复验时按[模板提取与复验](../../../system-development/references/template-fidelity.md)对照来源、示例输入和运行证据，具体判定采用本系统用例。

由未参与本轮实现的 agent 执行。读取[开发契约](../development/SKILL.md)、[开发规范](../../../development-rules/SKILL.md)、[Widget](../../../widget/SKILL.md)、[Entity](../../../entity/SKILL.md)。核实显式项目 ID 和 verified Unity 绑定；同一 Editor 串行操作，修改交回开发 agent。

冻结实际模板版本与交付文件哈希，测试范围按产品契约确定，当前本地范式至少检查：

| 项目 | 必需证据 |
| --- | --- |
| 收件箱 | 空、单封、多封、长正文和可滚动列表，排序、稳定 ID、选择与详情一致；没有产品数据才使用可辨识示例。 |
| 已读/删除 | 选中标记已读；未读或待领取附件不允许删除；删除已读保留不合格邮件；清空后关闭重开仍为空。 |
| 领取 | 单封、全部、重复、过期、无附件；凭据数量及内容正确。删除后重导同 ID 不重复领取，不发生真实背包/网络写入。 |
| 实体 | 可变输入/输出隔离、重复 ID 和非法日期/附件原子拒绝、失败不改变状态。产品新增账号和持久化需求时补对应测试。 |
| 绑定与图片 | 三个 Widget 的 Metadata 逐字段检查；复用与快速切换时旧图片不会残留，新请求失败不显示上封图标；旧页回调不改变新页。 |
| 动画/生命周期 | 实际采样 Open、Close、信封及条目动画；关闭完成回调、重复打开、加载时停用、关闭中重开均不留下重复实例。 |
| 输入与视觉 | 真实点击命中、遮罩、列表选择、正文滚动、字体、NEW 标记、附件领取态；调用系统方法不证明按钮可点击。 |
| 配置与发布 | SYS_MAIL 行及源表哈希、导表输出、材料与脚本哈希完整；浏览器局限单独记录，不能据原生资源存在就判浏览器通过。 |

执行实际目标工程编译、Console、`gamecli verify code --project <ID> --system Mail` 和适用的 `verify prefab`。保留原始结果，未知组件/动画项补证，不能修改基准消除差异。运行探针不得进入模板业务脚本。

报告按 passed / failed / incomplete / not-applicable 逐项记录输入、预期、实际、截图/JSON、版本和未覆盖项；必需证据缺失就是 incomplete。保存到持久报告目录，清理临时实例并记录最终 Play 状态。验收不授权 Git 推送或数据库发布。
