# Actor 验收

由未参与本轮实现的 agent 执行。先读 [Actor 开发](../development/SKILL.md)、[共享编码规范](../../../development-rules/SKILL.md)、[Entity](../../../entity/SKILL.md)、[Core](../../../core/SKILL.md)。模板提取或模板交付同时按 [模板提取与复验](../../../system-development/references/template-fidelity.md) 核对本轮场景基准。

## 输入与边界

取得需求范围、工程身份、宿主集成入口、源码和资源版本、角色状态映射、配置与导表步骤、数据所有权和复现方式。明确哪些角色动作本轮已实现，哪些属于未来能力。Studio 任务验证显式项目绑定；不得用参考工程替代目标。

只验收并记录问题，不边验收边修改实现。开发者的证据可作为线索，但不能冒称独立执行。修复后以新版本复验受影响项。

## 验证矩阵

按本轮实现选择具体输入，不要求不存在的玩法或资源格式。

| 检查项 | 必须观察的结果 |
| --- | --- |
| 数据职责 | 实体没有场景或动画对象依赖；位置、属性和规则的唯一写入者明确；Shape 不回写权威数据，System 不重复计算角色业务规则。 |
| 实例与集合 | 至少两个角色的 ID、位置和当前状态互不污染；重复 ID、非法初始化不会提交部分集合；输入数组修改不会改变已接收的数据。 |
| 无显示逻辑 | 不创建 Shape 也能推进本轮角色逻辑；隐藏/禁用 Shape 后按约定继续推进，若宿主主动暂停则能区分暂停来源。 |
| 状态机接入 | ActorShape 实际继承 XActionStateMachine；各实例状态独立、注册不重复、更新不重复。验证本轮全部状态进入、切换和退出，不只检查类声明。 |
| 稳定表现 | 相同状态反复刷新不重启动画；多次进入动作按业务约定播放；动画、朝向和逻辑状态对应。需要临时状态时验证完成、中断和恢复。 |
| 重绑与替换 | 解绑不改实体，重新绑定显示当前位置与状态；销毁或替换 Shape 不重置计数/属性。池化已实现时验证不会串用旧实例数据。 |
| 释放与异步 | 宿主退出清理实体和显示；旧引用不能继续提交有效动作；迟到加载回调不能重建角色。重复进入或模块替换不重复实例或更新。 |
| 配置与资源 | 源表、生成别名、导出数据与加载顺序一致；必需条目、空值及必需动画缺失明确失败；场景路径查表，动画名引用集中常量；原生引用可解析。 |
| 产品集成 | 原交互链、输入阻挡和本轮目标画面保持正确；基础移动或动画成功不代表业务消费、战斗结算已经接通。 |

移动逻辑适用时检查不同步长、跨路点、大步长、零或非法时间、到达事件只发生一次。不要要求没有路线的角色实现 miniwow 的往返状态。

检查共享规范要求的结构、注释、序列化引用和成员格式。通过 GameCLI 执行目标 Actor 模块及变更宿主的适用代码检查，执行 Unity 编译并读 Console。只有涉及预制制作或变更时才执行对应原生资产检查；不要求非 UI 角色拥有 UI 页面 ID。

## 报告

分别记录静态边界、编译、状态机、数据隔离、资源表现及宿主集成的 passed / failed / incomplete / not-applicable，说明原始输出位置、版本或哈希、实际操作和未覆盖条件。必要项缺证据时总体为 incomplete。

缺陷给出最小复现、预期/实际与负责层，返回开发修复后复验；不得复用旧版本报告冒充当前通过。验收不授权提交、推送或发布模板。
