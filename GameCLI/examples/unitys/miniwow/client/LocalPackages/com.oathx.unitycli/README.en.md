### Removing a specific duplicate component

`components remove --component "Oathx.Widget.Metadata[1]"` removes the second matching component (zero-based), for either scene or `--asset` prefab targets. Omitting the selector preserves first-component removal. Negative, malformed and out-of-range indices fail without saving the prefab. This allows an extra component to be removed while preserving the original bindings.
